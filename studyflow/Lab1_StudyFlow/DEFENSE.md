# Коротко для захисту ЛР1

StudyFlow збирає студентські завдання і дедлайни. MVP працює локально, бо курс охоплює HTML, CSS та JS. Реєстрація, сервер і синхронізація заплановані після MVP. 20 функціональних вимог описують дії; 8 нефункціональних — якість. Референс Bootstrap Dashboard обраний безкоштовний, але реалізація власна.

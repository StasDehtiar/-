# Коротко для захисту ЛР2

header — шапка; nav — меню; main — основний вміст; footer — підвал. Один h1 задає тему сторінки. alt дає текстовий опис зображення, label пов’язує підпис і поле. required перевіряє заповнення, type=email — базовий формат; minlength обмежує довжину. Відносний шлях працює після перенесення каталогу. SVG — векторний формат малого розміру.

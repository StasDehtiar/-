# Коротко для захисту ЛР4

DOM — об’єктне представлення HTML. querySelectorAll знаходить картки; createElement створює абзац; append додає його в main. addEventListener обробляє click, submit, mouseenter, mouseleave і keydown. preventDefault скасовує стандартне надсилання. trim прибирає крайні пробіли. textContent відображає введення як текст. localStorage зберігає рядки, тому завдання перетворюємо через JSON.stringify/JSON.parse. try/catch обробляє пошкоджені дані. Це локальна перевірка форми без реального сервера.
